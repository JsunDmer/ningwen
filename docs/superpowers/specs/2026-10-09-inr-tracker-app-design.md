# INR 记录 App 设计方案（Android）

- 日期：2026-10-09
- 状态：设计初稿，待用户审阅
- 交付物：设计方案文档 + 可点击 HTML 高保真原型

## 1. 背景与目标

为需要长期监测 INR（国际标准化比值，常见于华法林等抗凝治疗人群）的用户，提供一款**简单实用**的 Android App，用于：

- 快速记录每次 INR 测量数值
- 一眼看清最近状态是否在目标范围内
- 回顾历史趋势（图表）
- 记录华法林用量与备注
- 到点提醒测量
- 导出数据给医生看

**核心原则**：录入尽量快、状态一眼看清、离线可用、数据只存本机、不做医疗建议。

### 目标用户

- 使用者本人或家属（**单用户**，只有一份档案）
- 以普通成年人为主，操作习惯常规
- 场景：家里/医院测完 INR 后随手记录；复诊前翻看趋势

### 非目标（YAGNI，明确不做）

- 不做账号体系 / 云同步 / 多患者管理
- 不做用药或剂量自动调整建议（医疗风险，越界）
- 不做社区、资讯、商城
- 不联网、无广告

## 2. 信息架构

底部 3 个 Tab + 一个全局快捷记录入口：

```
┌─────────────────────────────────────┐
│              首页                    │  ← 概览 + 最近记录 + FAB 记录
│              趋势                    │  ← 折线图 + 统计
│              我的                    │  ← 目标范围 / 提醒 / 导出 / 关于
└─────────────────────────────────────┘
                   [+ FAB]             ← 悬浮记录按钮（始终可见）
```

- **记录表单**：点 FAB 后从底部弹出（Bottom Sheet），保存后回到首页并刷新。
- **趋势**、**设置**为独立页面；设置内可进入子页（如目标范围）。

## 3. 数据模型（本地存储）

### 3.1 记录 Record

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string/int | 主键 |
| value | float | INR 数值，如 2.4 |
| measuredAt | datetime | 测量时间（默认当前） |
| doseTabs | float? | 当次华法林用量（片），可选 |
| note | string? | 备注，可选 |
| createdAt / updatedAt | datetime | 创建/更新时间 |

> `inRange`（是否达标）**不入库**，由目标范围实时计算。

### 3.2 设置 Settings（单条）

| 字段 | 默认 | 说明 |
|---|---|---|
| targetMin | 2.0 | 目标范围下限 |
| targetMax | 3.0 | 目标范围上限 |
| testIntervalDays | 7 | 下次测量间隔（天，用户自行填写） |
| reminderEnabled | true | 测量提醒开关 |
| theme | 浅色 | 浅色/深色 |

## 4. 关键界面设计

### 4.1 首页

从上到下：

1. **状态大卡片**
   - 大号「最近一次 INR」数字（如 `2.4`）
   - 状态标签：`达标` / `偏高` / `偏低`（配色：绿 / 红 / 蓝）
   - 与上次对比：`↑ 0.3` / `↓ 0.2` / `—`
   - 测量日期时间
   - `距下次建议测量还有 N 天`
2. **最近记录列表**：最近 5 条卡片，每条显示 INR、日期、用量、备注摘要；底部「查看全部」
3. **右下角 FAB「+」**：快速记录

### 4.2 记录表单（Bottom Sheet）

- **INR 数值**：数字键盘输入，大字号
- **测量时间**：默认现在，可改日期时间
- **华法林用量（片）**：可选，默认带出上次值，步进 0.25（如 1 / 1.25 / 1.5）
- **备注**：可选，提供快捷标签 `出血/淤青`、`饮食变化`、`漏服`、`感冒/感染`、`其他`
- **保存 / 取消**
- 校验：数值需在合理范围（如 0.5–10），超出时二次确认，防止误输

### 4.3 趋势页

- 折线图：X 轴时间、Y 轴 INR
- **目标区间绿色横带**（targetMin–targetMax）
- 超范围的点高亮（偏高红、偏低蓝）
- 时间范围切换：`1月 / 3月 / 半年 / 全部`
- 下方统计：平均值、达标率、最高 / 最低
- （用量曲线叠加列为**后续可选**，MVP 先只画 INR）

### 4.4 我的（设置）

- 目标范围（下限 / 上限）
- 下次测量间隔（天，用户自行填写）
- 测量提醒（开关）
- 数据导出 / 分享
- 关于 + 免责声明（本工具仅记录，不提供医疗建议）

## 5. 关键交互流程

### 记录一次 INR

```
首页 → 点「+」→ 表单填写 INR（→ 用量 / 备注可选）→ 保存
     → 回到首页 → 状态卡片与列表刷新 → 提示本次状态（达标/偏高/偏低）
```

- 整个流程控制在 **3 步以内**，首次进入即可完成记录。

### 编辑 / 删除

- 记录列表中点击某条 → 详情/编辑 → 可修改或删除（删除需二次确认）。

## 6. 达标判断逻辑

```
若 value < targetMin      → 偏低
若 targetMin ≤ value ≤ targetMax → 达标
若 value > targetMax      → 偏高
```

- 默认目标范围 2.0–3.0，可按医嘱在设置中调整（例如 2.5–3.5）。
- 仅做**状态标记**，不给用药建议。

## 7. 提醒机制

- 提醒**不是设定钟点**，而是按「**上次记录时间 + 间隔天数**」推算下次测量日。
- 间隔天数由用户在设置中**自行填写**（一般一周 7 天或两周 14 天）。
- 首页直接显示「**距下次测量还有 N 天**」；已过期为「已过期」。
- 到点发本地通知（如「该测 INR 了」）。
- （原型阶段：仅显示倒计时，不真正发系统通知。）

## 8. 数据导出 / 分享

- **CSV**：完整记录表，便于给医生或自行分析。
- **图片**：趋势图 + 关键记录摘要，一键分享。
- 通过系统分享面板发送（微信、邮件等）。
- 导出为用户**主动触发**，不做自动上传。

## 9. 技术实现建议（供后续开发）

| 项 | 建议 |
|---|---|
| 平台 | Android 原生（Kotlin + Jetpack Compose）或 Flutter |
| 存储 | Room / SQLite，纯本地，离线优先，无需账号 |
| 提醒 | WorkManager + 本地通知 |
| 图表 | 原生 Canvas 或轻量图表库 |
| 隐私 | 数据仅存本机；无网络权限（或仅导出时用系统分享） |
| 备份 | 支持导出 / 导入，防换机丢失 |

## 10. 非功能需求

- **易用**：字号偏大、对比清晰、单手可达（FAB 在右下）。
- **快速**：冷启动到可记录 ≤ 3 秒，记录 ≤ 3 步。
- **离线**：完全离线可用。
- **隐私**：无账号、无联网、无广告。
- **可靠**：输入校验、删除二次确认、数据可导出备份。

## 12. 已确认决策

1. 设计方向：**方案 A（首页概览 + 快捷记录）**。
2. App 名称：**凝稳**。
3. 目标范围：默认 2.0–3.0，**用户可在设置中自行设定**。
4. 提醒：不设钟点，按「上次记录 + 间隔天数」推算下次测量；间隔天数由用户填写（默认 7 天）。
