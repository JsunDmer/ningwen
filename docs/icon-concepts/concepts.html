凝稳 · App 图标方案

INR 记录 · 蓝色品牌底 · 适配 Android 自适应图标（前景居中安全区）
方案 A
血滴 · 稳带
白色血滴代表 INR/血液检测，横穿的绿色区间带代表"目标范围"，蓝点在带内 = 指标达标。语义最直白。
推荐 · 辨识度高
方案 B
达标仪表
指针落在绿色区间内，直接表达"INR 在目标范围内"。绿色段即设定区间，强调"达标判断"这一核心功能。
功能导向
方案 C
趋势线
一条上升折线 + 目标带，呼应"趋势"页。偏数据感，适合强调记录与走势。
数据感
方案 D
环 · 滴
圆环 + 绿色进度弧 + 中心血滴，像"健康/监测"类 App。简洁现代，视觉平衡好。
简洁现代
方案 E
波形 N
字母「N」（凝稳 Ningwen）+ 折线波形双关，绿点为达标读数。抽象、品牌化，适合做长期品牌标记。
品牌化
方案 F
汉字「稳」
取"凝稳"的"稳"，白色汉字 + 绿色基线（稳如基线）。中文辨识直接，但要保证字体在设备上可用。
中文直白
